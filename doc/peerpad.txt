*peerpad.txt*  Native live collaboration for Neovim 0.12+

COMMANDS                                            *peerpad-commands*

:Peerpad [port] [bind-address]
    Share the current named UTF-8 source buffer. Default: free port, 0.0.0.0.
:PeerpadJoin [host port token]
    Join the current source's advertised session, or an explicit session.
:PeerpadStop
    Disconnect with a notification. The owner also stops the server.
    Identical shared buffers return to the loaded source and are removed without
    closing splits. Other text stays in a [disconnected] snapshot; copy it into
    a normal buffer to save. The source is never overwritten or reloaded.
:PeerpadStatus
    Display role, revision, pending edits and peer cursor locations.

Use u and CTRL-R for your own shared edits. Only the owner can :write.
TCP is unencrypted. Keep tokens private and use a trusted network or tunnel.

SETUP                                               *peerpad-setup*
>
    require("peerpad").setup({ discovery = true, max_peers = 8, keymaps = true })
<
Suggested normal-mode keys (off by default; existing maps are preserved):
    <leader>Ps   Start sharing
    <leader>Pj   Join the current file's session
    <leader>Pq   Disconnect / stop hosting
    <leader>Pi   Show session information
P is uppercase. Press your leader key, Shift+p, then s/j/q/i.
Define mapleader before loading the plugin.
Use either keymaps=true or manual mappings, not both. For manual mappings,
replace the installation setup with keymaps=false and map the four commands
yourself; see README.md for a complete example. Commands remain available.

INSTALLATION                                        *peerpad-install*
>
    vim.pack.add({{ src = "https://github.com/Sunwook-Hwang/peerpad.nvim" }})
    require("peerpad").setup({ keymaps = true })
<
See README.md for lazy.nvim, packer.nvim and vim-plug examples.

max_peers includes the owner (2-64). Sidecars use .<name>.flash-share for
compatibility with FLASH. Only the active source editor prompts to join.
Safe Git exclusion or sidecar write failures leave manual joining available.
Source conflicts block saving. Maximum document size: 1 MiB.
Shared acwrite buffers do not automatically attach language servers.

NEOVIM 0.13                                         *peerpad-compat*

Shared buffers and disconnected snapshots are excluded from native session
writes, including :restart. Session files cannot restore TCP connections or
peerpad:// scratch text. Before restarting, owners should :write synchronized
changes; guests should copy retained snapshots into normal files. Reconnect
after restarting. Visible shared windows serialize their original source,
or an empty view if it was removed. Live buffers and views are restored
after each session write.
Native autoread, Q and . are unchanged. Neovim 0.12 behavior is unchanged.

See README.md and README.ko.md for installation and the full safety model.
